# Security Policy

## Reporting a vulnerability

Please report security issues privately, not as a public issue.

Use GitHub's private vulnerability reporting (the "Report a vulnerability" button
under the repository's Security tab), or contact the maintainer directly.

Include a description, steps to reproduce, and the potential impact.

## Scope

This policy covers the code in this repository: the framebuffer embedder, the Dart
input layer, and the build/deploy tooling. The device firmware and the Flutter
engine itself are out of scope.
